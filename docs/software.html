Software & guides

My software projects address different parts of statistical practice: the linear algebra needed for repeated model fitting, the construction of sparse regression models, and the assessment of posterior or model-selection uncertainty. Each project brings together an implementation and a guide explaining the methodological choices behind a worked analysis.

The entries below outline what each project does and suggest an example through which to explore it. Links connect the software to related research where the relationship is documented; a computational connection does not imply that a single article covers every model implemented in a package.

Numerical linear algebra

fastQR

Fast QR factorization and updating methods for statistical computations.

Useful when the design changes repeatedly, as in model exploration and sequential analysis.

Methods

QR factorization; updating and downdating; least-squares computations.

An example to explore

Update a regression fit after adding or removing observations or predictors, and compare the result with a fresh factorization.

Related research

  • Fast QR updating methods for statistical applications

The QR updating paper develops the computational methods underlying this project.

Functional regression

fdaSP

Functional regression with sparsity-promoting penalties, with examples of estimation, selection and interpretation.

Connects sparsity in coefficient functions with interpretable functional regression.

Methods

Function-on-scalar and function-on-function regression; sparsity-promoting penalties; MM and ADMM optimization.

An example to explore

Estimate a functional regression surface and examine where the fitted effect is locally zero, alongside the inflation application in the guide.

Related research

  • Locally Sparse Function-on-Function Regression
  • Interpretable functional linear regression via local sparsity promoting penalty

The linked papers develop local sparsity for function-on-function and scalar-on-function regression.

Bayesian variable selection

fastBVS

Bayesian variable selection, posterior summaries and model-averaged prediction, supported by fast matrix updates.

Examines uncertainty over competing sparse models rather than reporting a single selected support.

Methods

Spike-and-slab regression; MCMC; posterior inclusion summaries; model averaging.

An example to explore

Use the inflation analysis to compare posterior inclusion probabilities, coefficient uncertainty and model-averaged predictions.

Related research

  • Fast QR updating methods for statistical applications

The QR updating paper provides related computational background; it is not a separate validation of every fastBVS model.

Read the guideSource code
Bayesian distributional regression

bquantreg

Bayesian quantile regression with worked housing-price analyses and comparisons across regression methods.

The guide distinguishes conditional means from conditional quantiles and examines posterior uncertainty and computation.

Methods

Gaussian and asymmetric-Laplace quantile models; shrinkage priors; nonlinear, spatial and GMRF effects.

An example to explore

Follow the independent Munich rental-price and Padova housing-price analyses, progressing from two-regressor models to nonlinear and spatial specifications.

Read the guideSource code
Penalized regression

SPARES

Regularization paths for sparse and adaptive regression, with degrees of freedom and model-selection tools.

Combines estimation, prediction and model selection in a common workflow. The public repository hosts the documentation; follow the guide for package installation.

Methods

Lasso; Group Lasso; overlapping groups; adaptive and sparse-group variants; pathwise complexity and selection tools.

An example to explore

Compare coefficient paths and local divergence along a regularization grid, then examine how the selection criterion changes with the penalty and adaptive weights.

Read the guideRepository

Choosing a starting point

For functional responses or covariates, fdaSP focuses on interpreting sparsity in estimated coefficient functions. SPARES concerns regularization paths for linear regression, including grouped and adaptive penalties. fastBVS treats variable selection through posterior distributions over models, whereas bquantreg develops Gaussian and quantile regression with flexible structured effects. fastQR supplies numerical methods for situations in which the design matrix changes repeatedly.

The guides explain their own dependencies and examples. Follow the installation instructions for the relevant project; a guide repository may contain documentation rather than the package source. CRAN links are provided only for projects with an identified CRAN page.
